Selector de elemento

El element selector selecciona elementos HTML en función del nombre del elemento.

Selector: ID

El idselector utiliza el atributo id de un elemento HTML para seleccionar un elemento específico. El ID de un elemento es único dentro de una página, por lo que el selector de ID se utiliza para seleccionar un único elemento. Para seleccionar un elemento con un ID específico, escriba el carácter de almohadilla (#), seguido del ID del elemento.

Selector Class

El classselector selecciona elementos HTML con un atributo de clase específico. Para seleccionar elementos con una clase específica, escriba un punto (.), seguido del nombre de la clase.

Selector Universal *

Selecciona [universal selector (*)] todos los elementos HTML de la página.

Hover

La :hoverpseudoclase CSS se utiliza para seleccionar elementos cuando se pasa el ratón por encima de ellos.

Insertar CSS

El CSS se puede insertar en un documento HTML de tres formas diferentes: en línea, interno y externo.

  • En línea
  • Interno
  • Externo

Box Sizing

La box-sizing propiedad CSS define cómo calcular el ancho y la altura de un elemento: si el cálculo debe incluir el relleno y los bordes, o no.

Transform

Esta transform propiedad aplica una transformación a un elemento. Permite rotar, escalar, mover, inclinar, etc., los elementos.
