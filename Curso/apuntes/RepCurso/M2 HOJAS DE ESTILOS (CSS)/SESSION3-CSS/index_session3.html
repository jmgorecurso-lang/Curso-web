Session 3 || CSS - Pseudoclases y Pseduelemento - Neumorfismo

Pseudoclases

  • :hover - Aplica estilos cuando el usuario pasa el cursor sobre un elemento.
  • :active - Aplica estilos mientras un elemento está siendo activado (por ejemplo, mientras se hace clic en él).

Pseudoelementos

  • ::before - Inserta contenido antes de un elemento.
  • ::after - Inserta contenido después de un elemento.

Neumorfismo

El neumorfismo es un estilo de diseño que combina elementos de diseño plano y Neumorfismo, creando interfaces que parecen surgir del fondo.
